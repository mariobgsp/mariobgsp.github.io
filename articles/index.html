routre

01

Cutting Agent Token Bills by 94%: the Architecture of a Local LLM Gateway

routre is one static Go binary that sits between your coding agents and every LLM provider. It compresses the tool output that dominates agent traffic, replays identical requests from cache, and fails over to the next provider when one is busy — while holding the API keys so the client never sees them.

StackGo 1.26, standard library only — no Node, Python, Postgres or Redis

Chats That Survive a Crash: Durable Agent Conversations on a SQLite Task Log

A local agent chat where closing the browser, killing the server, or losing the network costs you nothing: every message, tool call and generation is a durable task in SQLite, so the work in flight is still there when you come back. Agents are two markdown files, and groups of them talk to each other on their own.

StackSvelte 5 (runes) + Vite 8 · Fastify + WebSocket · SQLite via @earendil-works/pi-durable 1.3.0
