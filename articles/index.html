routre

01

A Local LLM Gateway That Cuts Agent Token Bills

routre is one static Go binary between your coding agents and every LLM provider. It compresses the tool output that dominates agent traffic, replays identical requests from cache, and fails over to the next provider when one is busy — while holding the API keys so the client never sees them.

StackGo 1.26, standard library only — no Node, Python, Postgres or Redis

durable-agents

02

Agents That Survive a Crash

A local agent fleet you drive from Telegram: one daemon owns the durable state, so a dropped long poll, a killed process or a lost network costs you nothing. Agents can message each other, run on schedules, edit their own system — and there is no browser left to reload.

StackNode + TypeScript (packages/cli · packages/core · packages/telegram) · one daemon over a 0600 Unix socket · Telegram Bot API · SQLite via @earendil-works/pi-durable 1.3.0

payment-system

04

One Go Binary Instead of Four Java Services

This payment system used to be four Java microservices on Kafka, Mongo and Zookeeper. It is now one Go binary, two Postgres schemas, and an outbox table doing the job the message broker used to do. All five containers start with one command.

StackGo (net/http stdlib) · PostgreSQL 15 · Redis 7 · Next.js portal · Docker Compose

05

An API Gateway That Keeps JWTs Out of the Browser

The Gateway is a small API-management console: define the upstream APIs you call, allowlist what may reach them, and test them from the UI. The interesting part is not the CRUD. It is that the session token never becomes readable by a single line of browser JavaScript.

StackNext.js 15 (BFF) · Go 1.26 + chi + pgx · PostgreSQL 15 · Docker Compose / Kubernetes
