02 Method

Same method, different sensors.

I trained as an engineering physicist, so the habit came first: define the quantity, instrument it, measure it, and report the scope of the measurement. I now apply it to services instead of fields.

  1. 2017 — 2021

    B.Eng Engineering Physics Universitas Gadjah Mada

    Sensors, measurement and control as the core, plus laboratory assistant work for the Sensor and Telecontrol Systems course in the Department of Nuclear Engineering and Engineering Physics.

  2. 2021

    Thesis Thermal-camera CNN

    Emotion identification from thermal-camera CNNs for a psychotherapy measurement instrument: a skin-temperature field became a model input.

  3. 2021 — 2023

    E-Payment XL Axiata

    Payment traffic instrumented instead of temperature — Java 17, Go, Solace, Oracle and Elasticsearch on Kubernetes, with APIs published to the API Gateway.

  4. 2023 — 2024

    CCPL Octo Smart CIMB Niaga

    A 1M-record batch job from ~6 hours to ~20 minutes — the same input, one wall-clock measurement.

  5. 2024 — now

    Regional services OCBC Indonesia

    API and system design alongside technical architects, SOA migration, and AI-augmented delivery across ID, SG, MY and CHN.

The unit changed from kelvin to milliseconds; the method did not.
